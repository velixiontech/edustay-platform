# 🎓 EduStay Platform

> Student Accommodation Management System for EduStay Accommodation (Pty) Ltd.

## Overview

EduStay Platform is the central operating system for EduStay Accommodation.

It manages:

- Student applications
- Student placements
- Property management
- Contracts
- Payments
- Maintenance
- Reporting
- Administration

The platform is designed with scalability in mind and may later evolve into a commercial Student Accommodation Management System under the Velixion brand.
